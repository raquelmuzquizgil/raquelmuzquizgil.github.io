One line of logic, every language

Click a language. The AMPscript below highlights the branch that renders, and the message updates live, the same logic running across 500K inboxes.

Vos points 
ELSEIF @user_language == "fr" THEN
  SET @message = "Vos points"
ELSEIF @user_language == "it" THEN
  SET @message = "I tuoi punti"
ELSEIF @user_language == "pt" THEN
  SET @message = "Os seus pontos"
ENDIF

Personalisation logic that adapted every email by language, purchase history and loyalty points balance, deployed across 500K subscribers via Salesforce Marketing Cloud.
